#### Key Findings

**1. Label flipping is catastrophically destructive to explanations:**
- Breast Cancer + LogReg: Spearman ρ drops to **0.28** (essentially random) at all noise levels
- Breast Cancer + XGBoost: ρ drops to **0.37–0.57**
- Heart Disease + LogReg: ρ = 0.70–0.79
- Heart Disease + XGBoost: ρ = 0.77–0.88
- Diabetes is most resilient: ρ stays above 0.84 for both models

**2. Gaussian noise and feature dropout barely affect explanation rankings:**
- Spearman ρ > 0.95 in almost all cases
- Top-3 Jaccard = 0.8–1.0 across the board
- Rankings are preserved even at 15% perturbation

**3. XGBoost has high Lipschitz ratios under Gaussian noise:**
- Heart Disease: L = **7.67** at 5% noise (magnitude-sensitive despite rank-stable)
- Diabetes: L = **3.12** at 5% noise
- LogReg: L stays below 0.67 (much more magnitude-stable)
- This is a novel finding: rank stability ≠ magnitude stability

**4. High-dimensional data (Breast Cancer, 30 features) is more fragile:**
- LogReg label-flip Spearman ρ = 0.28 (Breast Cancer) vs 0.84 (Diabetes, 8 features)
- More features → more ways for label noise to redistribute importance

**5. Lipschitz = 0 for label flip is expected:**
- X_test doesn't change, only the model changes → ΔX = 0 → ratio undefined/0
- Need a model-space Lipschitz metric for label perturbation (future work)
